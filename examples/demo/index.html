endor.mbt — get wallet address

This demo detects MetaMask, requests the connected wallet address, sends the chain's native currency, switches chains, and reads and transfers an ERC-20 token through the ABI layer, using the endor MoonBit SDK (compiled to JavaScript). Everything below the heading is rendered from MoonBit with luna.mbt, so the wallet values appear on the page rather than in the console.

The send button spends real funds on whatever chain the wallet is on, so point it at a testnet first — the Sepolia and Polygon Amoy buttons switch to one, adding it to the wallet if it has never seen it. Both have public faucets.

The token card takes any ERC-20 address on the chain the wallet is on — paste one and press Load token. Reading it (name, symbol, decimals, balanceOf) is four eth_calls and costs nothing; Send tokens is a real transfer and prompts the wallet.
